# 第三版有界预实验结果交接（2026-10-18）

本轮研究问题是：能否预测首个拒绝位置，提前准备纠错后的草稿；能否在边侧计算和切换预算内选专家，最终减少真实确认输出的端到端时间。协议见 [program.md](program.md)。以下均为 **Qwen3-8B 教师公共前缀上的诊断**，不是异步边云或在线加速实测；独立输出正确性与 WAN 时延尚未测。

| Gate | 实际工作 | 结论 |
|---|---|---|
| P0 资产和隔离 | 沿用 v2 冻结的 0.6B 五领域 LoRA、MIX80 与目标教师记录；v3 只写独立目录，远端 Python 为 `spec`；原始提案逐 token 重放核对 | 数据与静态草稿诊断可用；**新分支解码器的端到端正确性未验证** |
| P1 拒绝位置 | `router_train` 每任务 96 条；按请求 ID 固定划分拟合 290、校准 95、留出 95；留出中 81 条有足够长的历史/当前公共窗口，共 1,235 个窗口 | 早拒绝（前 4 token）Brier：全局 0.2491、仅历史 0.2445、领域＋专家＋历史 0.2176。按请求平均的 Brier 改善 0.0436，95% bootstrap 区间 [0.0169, 0.0707]。**有可预测信号**，但 32-token 间隔的教师窗口不是连续在线轨迹 |
| P2 提前分支 | 留出请求每任务固定取 15 条共 75 条；64 条具有合格 position32 窗口。根据冻结模型预测拒绝位置，预生成草稿 top-2 的第二候选纠错根与最多 3 个后缀 token | 64 条中拒绝 53 条，预测位置精确命中 15 条；34 次实际起分支仅 **2 次根命中、共复用 4 个后缀 token**。新缓存参考实现分支总耗时约 5.684 s；此操作尚无净收益证据。另一条“完整替代专家草稿”的纯离线代理在 242 个拒绝窗口里仅 18 次根命中；不能把替代提案成本当零 |
| P2 预算专家 | 使用拟合集上的 prompt-only 领域分类、任务专家先验与已观察接受反馈；12 组参数只在校准集选一组，留出集一次测评。每个公共窗口只选一个专家 | 留出 95 条／342 窗口，选择策略平均接受 3.734，MIX80 为 3.880；按请求配对差 −0.130 token，95% 区间 [−0.289, +0.033]，还发生 24 次专家切换。事后 Oracle 4.076 仅为质量上限，不抵成本 |
| P3 在线异步与 RL | **未运行** | P2 未给出覆盖计算/切换成本的信号；没有可验证的两端 WAN 运行条件。按协议停止，不把离线代理外推成真实加速 |

P1 的两种改善数字口径不同：0.2445−0.2176＝0.0268 是所有窗口等权的 Brier 差；0.0436 是先在每请求内平均、再按请求等权的配对差。训练、校准、留出按**请求**隔离；短回答不删，明确计入不合格覆盖。P2 的分支脚本首次试跑发现 PyTorch BF16 相同最大 logit 时 `topk` 与生产解码器 `argmax` 的 tie-break 不一致，已留失败记录并在独立 v2 输出路径修复为 `argmax`，再次逐 token 重放 75 条后才汇总。旧失败样本没有被悄悄剔除。

第二版强基线已经显示同卡 COST-UCB 速度仅为 AR8 的 0.356 倍、比 MIX80 慢；本轮没有改变该负结论。P1 预测信号可用于以后研究**不生成分支的低成本长度控制**，但 SVIP 已做熵驱动长度、E²-SCI 已做历史惯性和异步流水线、SpecBranch 已做提前分支；当前结果不足以提出“首次”算法或训练 RL 策略。[E²-SCI](https://openaccess.thecvf.com/content/CVPR2026/html/Li_E2-SCI_Elastic_Edge-Cloud_Speculative_Decoding_via_Credit_Inertia_CVPR_2026_paper.html)、[SVIP](https://arxiv.org/abs/2411.18462)、[SpecBranch](https://arxiv.org/abs/2506.01979)、[MetaSD](https://arxiv.org/html/2604.05417) 是下一版必比基线。

若以后继续，应先采集**连续在线**轮次的草稿熵、margin 与每轮目标验证时延，测独立校准后预测是否仍有效；再用真实 4090→云端网络记录检验延迟能否掩蔽分支计算。纠错根可探索多候选，但必须把分支 token、KV、上行字节和云端验证一起计费。只有单步策略与强基线的实际时间相当且逐 token 输出严格一致，才有理由训练成本约束 RL；当前不启动耗时训练。
